1. The frame

Three screens before a match still use the plain card of app.css (a 420 px box on an empty page), while the start menu around them is now the "Front" frame: the real map as the postcard, a text rail, the player in the corner. Now is today's client; R, D, P, T are four restyles of the same states in the language of the menu (the real map, huge type, the unit triangle, dashed roads, keys in square brackets, state by shape and not by colour alone). Pick a screen and a state above; the account (guest, calibrating, rated) changes the corner chip and the "Unrated" note; queue ban adds the amber chip and ring that every screen carries while the queue is locked. Click inside a frame: lobby rows, maps, bot levels, tabs, Copy, Ready and Create work, and Back returns to the menu.
