1. The frame

The start menu is what a player sees first. Now is the current client (a 420 px card, four equal blue buttons, no background; frames taken from the dev server and redrawn here with the same CSS). A-D are four different answers to the same list of screens. Every variant shows the same states: a guest or an account, the queue (searching, a long wait with the bot offer, an opponent found, confirmed), the queue ban with the time left, calibration k/5 (DEC-34), a network error, a match in progress, and the four secondary places (a bot, a friend, the public lobby, replays). Keys inside the frame: Enter Play, B bot, I friend, L lobby, R replays, Esc back; click the profile for the account menu. Side colours follow ui-style 6: your side is blue with one outline, the enemy is red with a double outline or a dashed outline and "?" when unknown; amber is for alerts, always with a !.
